# Working Terminology

This repository reuses upstream terminology wherever possible.

## Binding

A specification describing how one protocol or framework is carried or executed through another while preserving the source framework's semantics.

## Mapping

A non-normative comparison between concepts in two protocols or frameworks. A mapping does not imply semantic equivalence.

## Profile

A constrained set of choices, assumptions, or security requirements applied to an existing specification or binding.

## Experiment

Implementation or test work intended to validate assumptions, failure modes, or interoperability behavior.

## Upstream

The authoritative project or standards-development repository that owns the referenced specification.

## Consequential execution

Execution that can create externally visible or persistent effects, disclose sensitive information, or exercise authority on behalf of a subject.
