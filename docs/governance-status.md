# Governance & Status

Use this section to understand **who may claim what, what maturity means, and how repository changes are governed**.

## Governance invariant

The lab is an **experimental interoperability assurance workbench**. It can publish bounded local evidence about compositions it actually executes. It does not acquire normative authority over upstream specifications, and a successful local result does not become certification, legal authority, or production-conformance evidence.

## Navigation policy

Primary navigation is intentionally curated. New implementation notes, vectors, scenarios, generated matrices, experiment phases and evidence artifacts remain publishable and searchable, but **must not enter the primary sidebar automatically**.

A page belongs in primary navigation only when it is a stable reader-facing gateway that answers a recurring adoption or assurance question. Detail artifacts should be linked from their governing case or gateway page.

This is an information-architecture control: repository growth must not silently change the public documentation hierarchy.
