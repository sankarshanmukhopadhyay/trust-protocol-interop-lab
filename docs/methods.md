# Methods & Architecture

Use this section to understand **how the lab turns a cross-protocol question into a bounded, testable interoperability claim**.

## Core method

1. Define the composition question and actors.
2. Pin the source baselines.
3. Assign semantic ownership so one component cannot silently redefine another.
4. State invariants and boundary conditions.
5. Design positive, negative and adversarial scenarios appropriate to maturity.
6. Execute or review the scenarios and retain evidence.
7. Admit only the maturity claim supported by that evidence.
8. Escalate an upstream proposal only when the evidence warrants it.
