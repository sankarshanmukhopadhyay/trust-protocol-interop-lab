# Post-run handoff

After a successful and inspected workflow run, use the generated `provided_evidence` export to create a **new** source-pinned DPIP examination for the current OpenVTC revision. Do not rewrite the historical Dogwood examination. DPIP should admit or reject each requirement independently and preserve `ER-STATUS-AB` / `ER-TASK-AB` as evidence gaps if no other current attributable evidence is available.
