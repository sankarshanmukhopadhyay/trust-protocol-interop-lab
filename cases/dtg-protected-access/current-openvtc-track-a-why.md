# Why this execution exists

The earlier Dogwood package proved that the evidence machinery could observe a target-native durable binder and distinguish seeded from context-distinct cases. It did not prove anything about a later OpenVTC implementation. This tranche repeats the assurance question against an exact current source revision while preserving the old package as a regression comparator. That is the minimum needed to make the downstream DPIP examination about the implementation we actually mean to assure.
