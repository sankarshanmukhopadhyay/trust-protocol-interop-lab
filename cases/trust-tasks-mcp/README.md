# IC-TT-MCP-001 — Trust Tasks over MCP

**Status:** Candidate

This case registers the existing [MCP Binding for Trust Tasks v0.2](../../bindings/trust-tasks/mcp/0.2/spec.md) as a governed Interop Case without relocating its immutable versioned source.

## Question

Can MCP provide execution mechanics while Trust Tasks retain semantic work identity, correlation, response semantics, and ceremony continuity?

## Evidence posture

The binding has mature examples and a structured test plan but has not yet produced an executed multi-implementation evidence manifest. Candidate status therefore remains appropriate.

## Next gate
