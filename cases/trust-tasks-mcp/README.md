# IC-TT-MCP-001 — Trust Tasks over MCP

**Status:** Candidate

This case registers the current [MCP Binding for Trust Tasks v0.3](../../bindings/trust-tasks/mcp/0.3/spec.md) as a governed Interop Case without relocating its immutable versioned source.

## Question

Can MCP provide execution mechanics while Trust Tasks retain portable work identity, authorization boundaries, duplicate-execution protection, semantic task control, response/evidence semantics, and ceremony continuity?

## Evidence posture

The binding now derives sixteen testable invariants from the pinned Trust Tasks editor’s draft, including semantic task control, pre-effect authority re-evaluation, duplicate execution, payload validation, proof-omission boundaries, and task-digest evidence binding. It has not yet produced an executed multi-implementation evidence manifest. Candidate status therefore remains appropriate.

## Next gate

Execute positive and negative vectors against at least one reproducible runner, record results, and produce an evidence manifest before claiming `Interoperability Tested`.
