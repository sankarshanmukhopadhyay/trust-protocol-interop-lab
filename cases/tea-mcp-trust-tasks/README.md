# IC-TEA-MCP-TT-001 — TEA TSP, MCP, and Trust Tasks

**Status:** Experimental

This case registers the existing TEA ↔ MCP ↔ Trust Tasks mapping and experiment scaffolding as a single governed composition.

The experiment asks whether authenticated exchange and agent authority evidence can coexist with MCP execution mechanics and Trust Task semantic work without treating agreement state, authentication, delegation, invocation, or task correlation as equivalent.

See the [mapping](../../mappings/tea-mcp-trust-tasks.md) and [experiment scaffolding](../../experiments/tsp-enabled-ai-agents/README.md).

## Current Trust Tasks pressure point

The pinned Trust Tasks baseline now gives portable semantics to cancellation, suspension, resumption, duplicate-execution protection, and pre-effect authority checks. TEA/TSP authentication and MCP execution state remain inputs and mechanics around those semantics; neither should silently become the semantic owner of them.
