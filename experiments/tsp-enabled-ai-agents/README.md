# TSP-Enabled AI Agent Experiments

This directory is reserved for executable scenarios, test vectors, and observations derived from the [TSP-Enabled AI Agent Protocols Implementation Analysis 0.1](../../analysis/tsp-enabled-ai-agents/0.1/README.md).

Initial experiment families:

- `authenticated-exchange/` — state, replay, expiry, concurrency, and restart behavior;
- `delegation/` — ACDC processing, status, attenuation, composition, and policy failure;
- `mcp-over-tsp/` — identity binding, delegation presentation, tool invocation, portable result evidence, and downgrade behavior.

The directories intentionally begin as scaffolding. Test evidence should be added only when assumptions are made explicit and the expected result is reproducible.
