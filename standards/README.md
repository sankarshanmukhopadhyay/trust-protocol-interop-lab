# Portfolio Standards Intelligence

This directory contains the lab's governed external-standards intelligence layer.

## Source and acknowledgement

The initial discovery source is the **Global Standards Mapping Initiative (GSMI)** from the **Global Blockchain Business Council (GBBC)**. We gratefully acknowledge GSMI/GBBC for maintaining an open standards-mapping resource that helps identify relevant standards activity.

GSMI is used here as a **discovery catalogue**, not as normative authority. The authoritative source for a standard is its publisher. Inclusion in this register does not imply endorsement by GSMI, GBBC, or any standards body.

## Files

- `sources.yaml` — governed source register and attribution.
- `register.yaml` — portfolio-relevant standards and local dispositions.
- `mappings/portfolio.yaml` — relationship vocabulary and project analysis lenses.
- `schema/standard-entry.schema.json` — machine-verifiable entry contract.
- `methodology.md` — admission, mapping, assurance and monitoring method.
- `generated/standards-register.md` — generated human-readable register.
- `generated/portfolio-matrix.md` — generated project applicability matrix.

## Governance invariant

**Discovery is not dependency. Mapping is not endorsement. Verification is not authority.**

A standard becomes a normative local dependency only where an exact repository requirement, profile or implementation contract explicitly makes it one.
