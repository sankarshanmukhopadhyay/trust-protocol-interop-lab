# Support

This repository is an independent experimental interoperability laboratory. It does not provide production support, certification, or an SLA.

## Where to ask

Use a GitHub issue for reproducible defects, documentation problems, experiment failures, interoperability questions, and proposed repository changes. Use GitHub Discussions for exploratory questions that do not yet justify a tracked change.

For security-sensitive matters, follow [SECURITY.md](SECURITY.md) and do not disclose details publicly.

## What to include

For technical support requests, identify the relevant Interop Case or artifact, the pinned upstream baseline where applicable, the command or workflow used, expected versus observed behaviour, and any evidence needed to reproduce the result.

## Authority boundary

Support provided here covers only this repository's mappings, experiments, evidence, generated views, and maturity claims. Questions about normative upstream behaviour should be taken to the authoritative upstream project.
